Skrypty Active Effects

Dokument opisuje aktualny, kanoniczny interfejs systemu. Skrypty testów pracują na konkretnej instancji klasy z module/tests.mjs. Nie istnieje równoległy płaski wynik ani wyzwalacze zgodności wstecznej.

Cykl testu

preRollTest
  → prepare / roll / evaluate / resolve
  → rollTest
  → transformacje i ponowne obliczenie
  → akcje wyniku
  → skutki uboczne
  → zapis test.serialize() na karcie czatu

Dla broni cykl dodatkowo wywołuje preRollWeaponTest przed rzutem oraz rollWeaponTest po obliczeniu wyniku. Te cztery nazwy są jedynymi publicznymi wyzwalaczami testów.

Argumenty testu

W wyzwalaczach testowych najważniejsze są:

PoleZnaczenie
args.actorAktor wykonujący test.
args.item / args.weaponPrzedmiot testu, jeżeli istnieje.
args.testKonkretna instancja klasy testu.
args.rollDataTen sam mutowalny obiekt co args.test.result.data.
args.eventContextMetadane: typ, podtyp, faza, reroll i edycja.

Modyfikacja przed rzutem

// Trigger: preRollTest
args.test.preData.attributeBonus =
  Number(args.test.preData.attributeBonus ?? 0) + 2;
args.test.preData.annotations.push("Premia +2 do cechy");

Modyfikacja wyniku

// Trigger: rollTest
args.rollData.effectActionSuccessBonus =
  Number(args.rollData.effectActionSuccessBonus ?? 0) + 1;
args.test.markDirty("effect-success-bonus");
this.addAnnotation("Dodatkowy sukces z efektu");

Skrypt Dialog

args.fields opisuje wartości wejściowe dialogu. Dostępne są między innymi: attributeBonus, skillBonus, modifier, finalDifficulty, maximumDifficulty, autoSuccess, annotations oraz modyfikatory kości.

// Trigger: dialog
args.fields.maximumDifficulty = "hard";
args.fields.autoSuccess = true;
args.fields.annotations ??= [];
args.fields.annotations.push("Automatyczny sukces z Cechy");

maximumDifficulty jest twardym sufitem końcowej trudności: nawet jeżeli suma modyfikatorów wskazuje Luck lub Very Hard, wynik zostanie ograniczony do ustawionego poziomu. finalDifficulty ustawia końcowy poziom testu.

Adnotacje

this.addAnnotation("Tekst widoczny na karcie rzutu");

Helper zapisuje adnotację w kanonicznym obiekcie testu. Działa w dialog, preRollTest, rollTest, preRollWeaponTest i rollWeaponTest.

Immediate i usuwanie

Opcja „Usuń skrypt po wykonaniu” dotyczy wyłącznie skryptu z wyzwalaczem immediate. Po udanym wykonaniu usuwana jest konkretna definicja skryptu, nie cały Active Effect. Operacje dropu czekają na zakończenie wszystkich skryptów Immediate, zanim otworzą kolejny wybór użytkownika.

Karta czatu i akcje wyniku

Karta testu zapisuje wyłącznie flags.neuroshima.test = test.serialize(). Po kliknięciu akcji system odtwarza dokładną klasę przez NeuroshimaTestFactory.fromData, wykonuje zmianę, przelicza test i zapisuje nową serializację. Brak classId oznacza nieprawidłową kartę — system nie zgaduje rodzaju testu.

Ważne: test otwarty wymaga dokładnie dwóch albo trzech kości. Jedna kość i więcej niż trzy kości są odrzucane przez evaluator.
