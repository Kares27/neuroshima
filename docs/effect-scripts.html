Skrypty efektów — testy

Triggery testów korzystają z jednego kontraktu: args.actor, args.item, args.test, args.context i args.eventContext.

Kolejność triggerów

  1. preRollTest
  2. preRollWeaponTest — tylko broń
  3. rzut i obliczenie wyniku
  4. rollTest
  5. rollWeaponTest — tylko broń

Dane testu

PoleZnaczenie
args.test.preDataDane wejściowe i modyfikatory.
args.test.resultAktualny wynik, kości, sukcesy, PP, obrażenia i adnotacje.
args.test.contextStan wykonania, w tym reroll i edited.
args.test.rollClassNazwa rzeczywistej klasy testu.

Triggery przed rzutem

// Premia do cechy i umiejętności
args.test.preData.attributeBonus =
  Number(args.test.preData.attributeBonus ?? 0) + 2;
args.test.preData.skillBonus =
  Number(args.test.preData.skillBonus ?? 0) + 1;

// Ostateczne przesunięcie trudności
args.test.preData.finalDifficultyShift =
  Number(args.test.preData.finalDifficultyShift ?? 0) - 1;

// Test nie może stać się trudniejszy niż Hard
args.test.preData.maximumDifficulty = "hard";

// Automatyczny sukces z zachowaniem normalnego rzutu
args.test.forceSuccess();

Triggery po rzucie

// Zmiana pojedynczej kości
args.test.replaceDie(0, 1);

// Modyfikacja sukcesów i Punktów Przewagi
args.test.addSuccesses(1);
args.test.addSuccessPoints(2);

// Wymuszenie rezultatu
args.test.forceSuccess();
// args.test.forceFailure();

// Adnotacja widoczna na karcie
args.test.addAnnotation("Premia z aktywnego efektu");

Nie zapisuj dokumentów Foundry w preData ani context; używaj UUID. Nie uruchamiaj ręcznie przeliczenia ani renderowania karty — pipeline zrobi to po oznaczeniu testu jako dirty.

Trwałe operacje

Triggery nadal wykonują modyfikatory podczas edycji i przerzutu. Skrypt, który aktualizuje dokument lub tworzy trwały efekt, musi sam zabezpieczyć side effect:

if (this.isRecalculation) return;
// trwała aktualizacja dokumentu

Dialog testu

// W triggerze dialog można wymusić sukces:
args.fields.autoSuccess = true;

// Ograniczyć maksymalną trudność:
args.fields.maximumDifficulty = "hard";

// Dodać adnotację:
args.fields.annotations ??= [];
args.fields.annotations.push("Modyfikator z dialogu");
